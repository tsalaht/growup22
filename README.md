# GrowUp - تطبيق إدارة المهام الذكي

تطبيق شامل لإدارة المهام والملاحظات والأهداف المالية باللغة العربية، مبني بـ React Native و Expo.

## 📱 المميزات

### 🎯 إدارة المهام
- إنشاء وتنظيم المهام حسب الفئات والأولوية
- مهام يومية، أسبوعية، شهرية، وسنوية
- تذكيرات ذكية وإشعارات
- تتبع التقدم والإحصائيات

### 📝 الملاحظات الذكية
- إنشاء ملاحظات مع دعم الصور والمرفقات
- تصنيف الملاحظات حسب الفئات
- تذكيرات مرتبطة بالوقت والموقع
- البحث المتقدم في الملاحظات

### 💰 إدارة الأهداف المالية
- تحديد أهداف مالية طويلة المدى
- تتبع التقدم والمدخرات
- خطط الادخار الشهرية
- تقارير مالية تفصيلية

### 🔔 النظام الذكي للإشعارات
- إشعارات مخصصة لكل نوع من المحتوى
- إعدادات متقدمة للإشعارات
- ساعات الهدوء والتحكم في التوقيت

## 🏗️ البنية التقنية

### التقنيات المستخدمة
- **React Native** - إطار العمل الأساسي
- **Expo** - منصة التطوير والنشر
- **TypeScript** - للأمان النوعي
- **AsyncStorage** - تخزين البيانات المحلية
- **Expo Router** - نظام التنقل
- **Lucide Icons** - الأيقونات

### بنية المشروع
```
├── app/                    # صفحات التطبيق (Expo Router)
│   ├── (tabs)/            # صفحات التبويبات الرئيسية
│   ├── auth/              # صفحات المصادقة
│   ├── onboarding/        # صفحات التعريف بالتطبيق
│   └── _layout.tsx        # التخطيط الجذر
├── components/            # المكونات القابلة لإعادة الاستخدام
├── contexts/              # سياقات React للحالة العامة
├── constants/             # الثوابت والألوان
├── types/                 # تعريفات TypeScript
├── utils/                 # الدوال المساعدة
└── services/              # خدمات التطبيق
```

## 🔧 إعداد المشروع

### المتطلبات
- Node.js 18+
- Bun أو npm
- Expo CLI
- محاكي iOS/Android أو جهاز فعلي

### التثبيت
```bash
# استنساخ المشروع
git clone [repository-url]
cd growup-app

# تثبيت التبعيات
bun install

# تشغيل التطبيق
bun start
```

### البيئة التطويرية
```bash
# تشغيل على الويب
bun run start-web

# تشغيل مع التصحيح
bun run start-web-dev
```

## 📁 الملفات الرئيسية

### التخطيط والتنقل
- `app/_layout.tsx` - التخطيط الجذر مع مقدمي السياق
- `app/index.tsx` - صفحة التوجيه الرئيسية
- `app/(tabs)/_layout.tsx` - تخطيط التبويبات

### إدارة الحالة
- `contexts/AuthContext.tsx` - سياق المصادقة
- `contexts/TaskContext.tsx` - سياق المهام
- `contexts/NotesContext.tsx` - سياق الملاحظات
- `contexts/FinanceContext.tsx` - سياق الأهداف المالية

### الثوابت والأنواع
- `constants/index.ts` - الألوان والثوابت
- `types/index.ts` - تعريفات TypeScript
- `utils/index.ts` - الدوال المساعدة
