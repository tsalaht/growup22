# دليل مفاتيح الإعلانات المستخدمة 🔑

## ✅ **المفاتيح النشطة:**

### **1. إعلان البانر (Banner Ad)**
```
ca-app-pub-1029952950379935/4771062361
```
- **الاستخدام**: إعلان مستمر في أسفل الشاشة
- **النوع**: مستطيل صغير
- **المدة**: مستمر
- **الموقع**: أسفل جميع الشاشات

### **2. إعلان الفيديو البيني (Interstitial Video)**
```
ca-app-pub-1029952950379935/3838675529
```
- **الاستخدام**: فيديو 3 ثواني
- **النوع**: شاشة كاملة
- **المدة**: 3 ثواني
- **الموقع**: عند الضغط على "شاهد الفيديو"

## 📱 **كيفية الاستخدام:**

### **في وضع التطوير:**
- يستخدم مفاتيح تجريبية من Google
- لا تظهر أرباح حقيقية
- للاختبار فقط

### **في وضع الإنتاج:**
- يستخدم المفاتيح الحقيقية أعلاه
- أرباح حقيقية
- إعلانات حقيقية

## ⚙️ **الإعدادات:**

### **ملف config/ads.ts:**
```typescript
// المفاتيح الحقيقية
BANNER_AD_UNIT_ID: 'ca-app-pub-1029952950379935/4771062361'
INTERSTITIAL_AD_UNIT_ID: 'ca-app-pub-1029952950379935/3838675529'

// المفاتيح التجريبية (للتطوير)
TEST_BANNER_AD_UNIT_ID: 'ca-app-pub-3940256099942544/6300978111'
TEST_INTERSTITIAL_AD_UNIT_ID: 'ca-app-pub-3940256099942544/1033173712'
```

## 🎯 **المواقع:**

### **إعلان البانر:**
- الشاشة الرئيسية (أسفل)
- شاشة الأهداف (أسفل)
- جميع الشاشات (أسفل)

### **إعلان الفيديو:**
- الشاشة الرئيسية (زر "شاهد الفيديو")
- شاشة الأهداف (زر "شاهد الفيديو")
- عند إكمال المهام
